# To-Do App

A browser-based task manager built with HTML, CSS, and JavaScript.

## Features

- Add tasks using the Add button or by pressing Enter.
- Mark tasks as complete.
- Delete tasks.
- Save tasks in the browser after refreshing the page.

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

Open `index.html` in a modern browser. No dependencies or build steps are required.

## Data Storage

Tasks are saved in your browser's local storage under the key `todo-tasks`.
